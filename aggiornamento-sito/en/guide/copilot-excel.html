Copilot in Excel: how to use it well

Copilot is Microsoft's AI assistant built into Excel. It can explain formulas, write them, summarize a table and suggest charts. Before you start, check that it is included in your Microsoft 365 license: availability depends on the plan.

What you can ask it

  • Explain a formula you do not understand, step by step.
  • Write a formula from a plain-language description.
  • Highlight outliers and trends in the data.
  • Summarize a table in a few sentences.
  • Suggest charts and summary tables.

First of all, prepare your data

An AI assistant only works well on tidy data. Check these points:

  • clear headers in the first row;
  • a single table per sheet, with no merged cells;
  • consistent formats for dates and numbers;
  • no total rows in the middle of the data.

6 prompts to try

PROMPT 1Explain this formula step by step: [paste the formula].
PROMPT 2Write a formula that sums the sales in column [C] when the region in column [B] is [North] and the month is [January].
PROMPT 3Highlight the rows with unusual values in the [Sales] column and explain why.
PROMPT 4Summarize this table in 5 points for an executive.
PROMPT 5Suggest three charts suited to comparing [indicator] across [regions] over time.
PROMPT 6Create a summary table with sales by category and by month.

Mistakes to avoid

  • Trusting without checking. Verify every result with a spot-check calculation.
  • Asking for everything at once. Work in steps: clean first, then analyze, then create the chart.
  • Using confidential data without checking the rules of your company.

From prompt to dashboard

With the same steps you get to a dashboard with linked filters and charts. You can try an interactive example on the home page or download the free Excel template and adapt it to your data.
